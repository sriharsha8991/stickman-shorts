light. Palette cream + electric purple + mint (coral = wrong, gold = the pick). Different from L001 (neon control room)
and the latest Shorts. Motion personality: Playful.

**Retention mechanics (all scenes):** a new element on almost every cue (≈3 s); an automatic screen transition every

covered frame: wide / content push-in / Spark close-up); a slow `drift()` on every camera; `punch()` on hits; one
chapter card (typewriter sheet + bell) on each 1 s chapter pause. Spark changes side and size in every chapter
(`sparkAt`, walks with `walkCycle`), never the same gesture twice in a row, 13 different moods.
