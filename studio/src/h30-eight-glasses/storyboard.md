# H30 storyboard — beat map + shot list (promise → build → reveal)
Series: Myth check · 36.6 s · ONE sunny kitchen ~2.5 screens wide, one camera rig. Announced move: "But an old report".
Place A x≈0–1200: butter wall, navy counter with eight glasses. Place B x≈1450–2400: lunch table (soup, watermelon, tea, glass, tall jug) under an old page rolled up at the bottom.
Motion language: Playful but calm. No power-up, no transition. Butter + navy + water blue: differs from V029 (crimson) and H16 (tangerine).
