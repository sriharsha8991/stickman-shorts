# V032 storyboard — beat map + shot list (promise → build → reveal)
Series tag: YOUR BRAIN DID THIS · 38.2 s · ONE world, one sideways camera rig, no cuts. Announced move: "Scientists tested this" → along the shop to the test floor; "So read the whole price" → back to the tag.
World: an evening pen shop. Aubergine walls + shelves, cream panels, walnut floor, marigold accents. Place A x 0–1100: hanging price tag + counter. Place B x 1360–2440: two pens on stands, tags above, a hundred little people.
Motion language: Playful. No power-up, no transition. Differs from H06 (periwinkle tower), V030 (peach + steel lab), H30 (butter kitchen).

## Beat map
| s | Beat | What |
