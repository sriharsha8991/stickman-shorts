# H17 storyboard — beat map + shot list (promise → build → reveal)
Series tag: YOUR BRAIN DID THIS · 36.2 s · ONE world, one camera rig (A ⇄ B plus a wide pull-back), no cuts. Announced moves: "You leave" → to the new task; "before leaving" → back to the desk.
World: a coral office in daylight. Place A x 40–460: desk + laptop with the unfinished email. Place B x 1100–1560: table + NEW TASK board with five blank sheets. A yellow rope runs from the laptop's corner to Spark's head.
Motion language: Playful. No power-up, no transition. Differs from V032 (aubergine shop), H06 (periwinkle tower), H16 (tangerine home office, price tag).
