# H14 · Willpower isn't a battery — facts (checked 2026-10-23)

| Claim (as used) | Verdict | Source |
|---|---|---|
| "Willpower drains like a battery" = the ego-depletion idea (self-control uses a limited resource; one act of self-control impairs the next) | Context (the belief being tested) | Hagger et al. 2016, Perspectives on Psychological Science 11(4):546–573 |
| 23 labs ran a preregistered replication of ego depletion | Confirmed | https://www.psychologicalscience.org/journals/perspectives/1745691616652873/ |
| Design: a first self-control task, then a second task measuring self-control ("one hard task, then another") | Confirmed (sequential-task paradigm, Sripada et al. protocol) | as above |
| 2,141 participants; effect d = 0.04, 95% CI [−0.07, 0.15] (includes zero) → "about zero" | Confirmed | as above |
| A bigger preregistered test (36 labs, N = 3,531) found a nonsignificant d = 0.06 → "A bigger test in 2021? Same result." | Confirmed | Vohs et al. 2021, Psychological Science 32(10):1566–1581: https://discovery.dundee.ac.uk/en/publications/a-multisite-preregistered-paradigmatic-test-of-the-ego-depletion- |
| Caveat: tested one paradigm/setup; the debate continues | Kept on screen and spoken | row caveat; both papers test specific task pairs |
| Takeaway "make hard tasks easy to start" | Advice/opinion, not presented as a study finding | — |
